## Review Focus

1. **空 store / t0===t1**：实例切换后首帧 `st.ts` 为空或单点 → `xFrac` 不得 NaN（T1 单测覆盖 `d<=0 → 1`）。
2. **down 断档（连续抓取失败）**：down 分支持续推 `ts`（`Date.now()`）+ 值 null → 时间轴留空档、轴继续滚动；`evict` 必须连同 null 一起 shift（T1 单测覆盖）。
3. **长时间空闲后 X 轴"卡住"**：draw 只在数据到达时重绘；刻度标签必须用**绘制时** `Date.now()` 计算（不得缓存 t1），T7 浏览器验收：暂停轮询 60s 后恢复，刻度对齐当前时间。
